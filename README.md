# AI-Hand-Gesture-Control-System

A real-time AI-powered hand gesture control system developed using Python, OpenCV, MediaPipe, and PyAutoGUI. This project allows users to control different computer functions using hand gestures through a webcam.

---

## 🚀 Features

* Volume Up / Down Control
* Play / Pause Media
* Next / Previous Controls
* Screenshot Capture
* Scroll Up / Down
* Open Chrome
* Open Calculator
* Open Notepad
* Close Active Window
* Real-Time Hand Tracking
* Interactive User Interface

## 📷 How It Works

The webcam captures real-time hand movements. MediaPipe detects hand landmarks and finger positions. Different hand gestures trigger different system actions automatically.

---

## ✋ Gesture Controls

| Gesture        | Action       |
| -------------- | ------------ |
| Thumb Up       | Volume Up    |
| Closed Fist    | Volume Down  |
| Index Finger   | Next         |
| Two Fingers    | Previous     |
| Three Fingers  | Play / Pause |
| Open Palm      | Screenshot   |
| Custom Gesture | Scroll Up    |
| Custom Gesture | Scroll Down  |
